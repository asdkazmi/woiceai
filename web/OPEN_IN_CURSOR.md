# How to Open in Cursor Designer

## Step 1: Open the Project in Cursor

1. **Open Cursor IDE**
2. **File → Open Folder** (or `Cmd+O` on Mac)
3. Navigate to: `/Users/asdkazmi/work/woice-ai/woice-ai-2.0/woice-ai-react-express`
4. Click **Open**

## Step 2: Using Cursor Designer

### Option A: Open Designer from Command Palette
1. Press `Cmd+Shift+P` (Mac) or `Ctrl+Shift+P` (Windows/Linux)
2. Type: `Cursor: Open Designer`
3. Select the command

### Option B: Open Designer from Component File
1. Open any React component file (e.g., `frontend/src/components/Login.tsx`)
2. Right-click in the editor
3. Select **"Open in Designer"** or **"Design"**

### Option C: Use Cursor Designer Panel
1. Look for the **Designer** icon in the sidebar (paintbrush icon)
2. Click it to open the Designer panel
3. Select a component file to edit

## Step 3: Design Your Components

Once in Cursor Designer:
- **Visual Editing**: Click elements to edit them visually
- **Code Sync**: Changes sync between Designer and code
- **Component Tree**: See component hierarchy
- **Props Panel**: Edit component props visually
- **Styles Panel**: Edit CSS visually

## Components Available for Design

- `frontend/src/components/Login.tsx` - Login page
- `frontend/src/components/Dashboard.tsx` - Dashboard page
- `frontend/src/components/Login.css` - Login styles
- `frontend/src/components/Dashboard.css` - Dashboard styles

## Tips

- Make sure the development server is running (`npm start` in frontend folder)
- Changes in Designer will reflect in real-time
- You can switch between Designer and Code view seamlessly
